# LM2: Testing, Debugging, and Source Control

## Project Purpose

This project uses PowerShell debugging and Pester testing to improve the resource group script from LM1.

## Files Included

- `lm2-lab.md` - Lab notes and testing results
- `create-resourcegroup.tests.ps1` - Pester test
- `README.md` - Project information
- `..\LM1\create-resourcegroup.ps1` - Updated Azure script

## Lessons Learned

I learned how to use verbose and debug output to follow a script while it runs. I also learned how Pester can automatically test whether the script worked. Git keeps a history of the changes and makes it easier to manage the project.
